JS 32x32 只处理 1024 个像素，通常很快；JS 96x96 和 WASM 96x96 都处理 9216 个像素，更适合比较同采样规模下的引擎差异。 WASM 是 PlainTab 的 C++ 正式主题色引擎，JS 是异常环境下的 fallback；两者不是逐行等价实现，所以颜色输出可能不同。 本页面已内联 PlainTab 的 WASM 主题色引擎，直接双击 HTML 也可以跑；通过本地服务器打开时同样有效。
