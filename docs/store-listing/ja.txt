PlainTab · ミニマルな新しいタブ

高速で静かな、壁紙中心の新しいタブページです。

新しいタブを開いたとき、最初に見たいのは心地よい壁紙、検索欄、必要なときだけ使う自分のリンクです。ニュースフィード、広告、トレンド、ウィジェットだらけの画面ではありません。

PlainTab は新しいタブをきれいで速く、落ち着いた場所に保ちます。検索する、URL を入力する、ショートカットを開く、壁紙ソースを切り替える。あるいは壁紙を一瞬眺めて、そのまま作業に戻れます。

PlainTab を選ぶ理由

【すぐに見える壁紙】

PlainTab は、新しいタブを開いた最初の瞬間を大切にしています。

軽量な壁紙プレビューをローカルに保存し、次回の表示でできるだけ早く画像を出します。完全な壁紙読み込み、キャッシュ、テーマカラー抽出はその後に処理します。

壁紙切り替えは 2 層構造です。現在の画像を表示したまま次の画像を読み込み、準備できたら自然にフェードインします。ネットワークソースが失敗しても、現在の安定した壁紙をできるだけ残します。

【柔軟な壁紙ソース】

PlainTab は以下に対応しています。

• Bing 日替わり壁紙
• Wallhaven
• ローカル画像アップロード
• ローカル壁紙フォルダー
• RSS 画像フィード
• カスタム画像 API
• 動画壁紙

シンプルに使うなら Bing。自分のコレクションがあるならアップロードやフォルダー。細かく作り込みたいなら RSS、API、Wallhaven が使えます。

【静かなホーム、必要な機能】

PlainTab はホームをショートカットで埋めず、新しいタブを別の情報フィードにしません。

ホームには壁紙、検索、少しの操作だけを残します。ショートカットはコマンドパレットで管理でき、検索、追加、編集、ブックマークのインポート、リンクの非表示ができます。

検索バーは位置、幅、角丸、透明度、表示モード、検索履歴、検索エンジン動作を調整できます。

【設定は深く、表示は静か】

設定は専用パネルにまとまっています。壁紙ソース、検索、ホットキー、コマンドパレット、見た目、バックアップ、言語などを調整できます。

【プライバシーと権限】

PlainTab には広告も追跡用分析もありません。

アップロードした壁紙、ショートカット、検索履歴、設定は主にブラウザーのローカルストレージに保存されます。アカウントは不要です。

権限は新しいタブ、検索、ページ操作、任意のオンライン壁紙ソースに関係します。RSS、API、Wallhaven は画像ソースへのアクセスが必要になる場合があります。

【軽量でオープン】

PlainTab は Vanilla JavaScript、CSS、ブラウザー API で作られています。フレームワーク、ビルド手順、大きな runtime 依存はありません。

プロジェクトはオープンソースで読みやすく、日常利用にもブラウザー拡張の学習にも向いています。

PlainTab はこんな人に向いています。

• フィードなしで美しい新しいタブがほしい
• 日替わり壁紙や自分の壁紙コレクションを使いたい
• 検索、ショートカット、ブックマークインポート、バックアップがほしい
• ホームを大量のタイルで埋めたくない
• 軽量で透明な拡張機能を使いたい

PlainTab が追加しないもの

• ニュースフィード、トレンド、推薦
• 広告やスポンサー枠
• アカウント、ソーシャル機能、クラウドコンテンツ
• ホームを埋める大量の固定ショートカット
• 自動再生の宣伝動画やフィード
