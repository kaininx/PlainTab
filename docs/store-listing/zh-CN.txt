PlainTab · 极简新标签页

一个快速、安静、以壁纸为中心的新标签页。

打开浏览器的新标签页时，你应该先看到一张舒服的壁纸，而不是新闻流、广告、热榜、推荐内容和满屏组件。

PlainTab 做的事情很简单：让新标签页保持干净、好看、反应快。你可以搜索、输入网址、打开快捷链接、切换壁纸来源，也可以什么都不做，只看一眼壁纸，然后继续自己的事。

为什么选择 PlainTab？

【打开就有画面】

PlainTab 很在意新标签页打开时的第一眼体验。

它会在本地保存轻量的壁纸预览，让下一次打开新标签页时尽量马上有画面；完整壁纸加载、缓存和主题色计算会在后续运行时处理，减少空白闪烁的感觉。

壁纸切换使用双图层设计：旧画面会留在底层兜底，新图准备好后再平滑淡入。即使网络来源失败，也尽量保留当前可见壁纸，而不是把页面清空。

【壁纸自由】

PlainTab 支持多种壁纸来源：

• Bing 每日壁纸
• Wallhaven 壁纸
• 本地图片上传
• 本地壁纸文件夹
• RSS 图片源
• 自定义图片 API
• 视频壁纸

如果你只想每天看到一张好看的图，可以直接使用 Bing 每日壁纸。如果你有自己的壁纸收藏，可以上传图片或选择本地文件夹。如果你喜欢折腾，也可以接入 RSS、API 或 Wallhaven。

【主页安静，功能不少】

PlainTab 不把快捷方式铺满主页，也不把新标签页做成信息流。

主页默认只保留壁纸、搜索栏和少量必要入口。快捷链接放在命令面板里管理：你可以搜索、添加、编辑、导入书签，也可以把一些链接放进隐藏空间，让主页继续保持干净。

搜索栏也可以按你的习惯调整：

• 位置
• 宽度
• 圆角
• 透明度
• 显示方式
• 搜索历史
• 搜索引擎行为

你可以让它一直显示，也可以让它在需要时出现。

【设置够用，但不打扰】

PlainTab 的设置集中在设置面板里，不会堆在主页上。

你可以调整壁纸来源、搜索栏、快捷键、命令面板、界面风格、数据备份、语言等内容。平时看到的是一个安静的新标签页；需要调整时，再打开设置。

【隐私与权限】

PlainTab 没有广告，也不做统计追踪。

本地上传的壁纸、快捷链接、搜索历史和配置数据主要保存在你的浏览器本机存储中。PlainTab 不需要账号系统，也不会把你的新标签页变成云端内容流。

扩展会使用与新标签页、搜索、页面交互和可选网络壁纸来源相关的权限。自定义 API、RSS、Wallhaven 等网络壁纸功能可能需要访问对应图片来源；如果你只使用本地或默认配置，也可以保持很简单。

【轻量透明】

PlainTab 使用原生 JavaScript、CSS 和浏览器 API 构建，没有前端框架、没有构建步骤，也没有大型运行时依赖。

项目开源，代码可以直接阅读。它既适合日常使用，也适合学习浏览器扩展、前端项目结构和 AI 协作开发。

适合你，如果你希望：

• 新标签页更好看，但不想被信息流打扰
• 喜欢每日壁纸，或者有自己的壁纸收藏
• 想要搜索、快捷链接、书签导入和备份能力
• 不喜欢主页被几十个快捷方式铺满
• 希望扩展轻量、透明、可本地运行
• 想研究一个真实完整的浏览器扩展项目

PlainTab 不会做什么：

• 不放新闻流、热榜或推荐内容
• 不放广告、赞助卡片或推广位
• 不加入账号系统、社交功能或云端内容流
• 不把主页铺满几十个快捷方式
• 不播放推广视频或内容流
