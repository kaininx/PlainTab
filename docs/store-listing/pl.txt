PlainTab · Minimalna nowa karta

Szybka, spokojna i skupiona na tapetach strona nowej karty.

Po otwarciu nowej karty najpierw powinna pojawić się przyjemna tapeta, wyszukiwarka i twoje linki wtedy, gdy ich potrzebujesz. Nie newsfeed, reklamy, trendy ani pulpit pełen widżetów.

PlainTab utrzymuje nową kartę czystą, ładną i szybką. Szukaj, wpisuj URL, otwieraj skróty, zmieniaj źródła tapet albo po prostu spójrz na obraz i wróć do pracy.

Dlaczego PlainTab?

[Tapeta od razu]

PlainTab dba o pierwszy moment po otwarciu karty.

Lekki podgląd tapety jest zapisywany lokalnie, aby przy kolejnym otwarciu obraz pojawił się jak najszybciej. Pełne ładowanie, cache i kolory motywu są wykonywane później.

Przejścia używają dwóch warstw: obecny obraz zostaje widoczny, a następny ładuje się i łagodnie pojawia. Jeśli źródło sieciowe zawiedzie, PlainTab próbuje zachować stabilną tapetę.

[Elastyczne źródła tapet]

PlainTab obsługuje:

• Codzienną tapetę Bing
• Wallhaven
• Wgrywane obrazy
• Lokalne foldery
• Feed RSS z obrazami
• Własne API obrazów
• Tapety wideo

Użyj Bing dla prostoty, lokalnych obrazów dla swojej kolekcji albo RSS, API i Wallhaven dla bardziej osobistej konfiguracji.

[Spokojna strona, przydatne narzędzia]

PlainTab nie zasłania strony skrótami i nie zamienia nowej karty w kolejny feed.

Strona zachowuje minimum: tapeta, wyszukiwanie i kilka kontrolek. Skróty są w palecie poleceń, gdzie można je wyszukiwać, dodawać, edytować, importować zakładki i ukrywać linki.

Pasek wyszukiwania pozwala ustawić pozycję, szerokość, zaokrąglenie, przezroczystość, widoczność, historię i zachowanie wyszukiwarki.

[Ustawienia bez bałaganu]

Ustawienia są w osobnym panelu. Możesz zmienić źródła tapet, wyszukiwanie, skróty klawiszowe, paletę poleceń, styl, kopie zapasowe, język i więcej.

[Prywatność i uprawnienia]

PlainTab nie ma reklam ani analityki śledzącej.

Wgrane tapety, skróty, historia wyszukiwania i konfiguracja są głównie przechowywane lokalnie w przeglądarce. Konto nie jest potrzebne.

Uprawnienia dotyczą nowej karty, wyszukiwania, interakcji ze stroną i opcjonalnych źródeł tapet online. RSS, API i Wallhaven mogą wymagać dostępu do swoich źródeł obrazów.

[Lekki i otwarty]

PlainTab używa vanilla JavaScript, CSS i API przeglądarki. Nie ma frameworka, builda ani ciężkiej zależności runtime.

Projekt jest open source i łatwy do sprawdzenia. Nadaje się do codziennego użytku i nauki na prawdziwym rozszerzeniu.

PlainTab jest dla ciebie, jeśli chcesz:

• Ładniejszej nowej karty bez feedów
• Codziennych tapet albo własnej kolekcji
• Wyszukiwania, skrótów, importu zakładek i kopii
• Strony bez dziesiątek kafelków
• Lekkiego i przejrzystego rozszerzenia

PlainTab nie doda:

• Newsfeedów, trendów lub rekomendacji
• Reklam albo sponsorowanych kart
• Kont, funkcji społecznościowych lub chmury treści
• Dziesiątek przypiętych skrótów
• Autoodtwarzanych filmów promocyjnych lub feedów
