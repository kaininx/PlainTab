PlainTab · 미니멀 새 탭

빠르고 조용한, 배경화면 중심의 새 탭 페이지입니다.

새 탭을 열었을 때 먼저 보고 싶은 것은 편안한 배경화면, 검색창, 필요할 때 꺼내 쓰는 내 링크입니다. 뉴스 피드, 광고, 트렌드 카드, 위젯으로 가득 찬 화면이 아닙니다.

PlainTab은 새 탭을 깔끔하고 빠르게 유지합니다. 검색하고, URL을 입력하고, 바로가기를 열고, 배경화면 소스를 바꾸거나 잠깐 이미지를 보고 다시 하던 일을 이어갈 수 있습니다.

왜 PlainTab인가요?

[바로 보이는 배경화면]

PlainTab은 새 탭이 열리는 첫 순간을 중요하게 생각합니다.

가벼운 배경화면 미리보기를 로컬에 저장해 다음에 열 때 가능한 한 빨리 이미지를 보여 줍니다. 전체 배경 로딩, 캐시, 테마 색상 계산은 이후 런타임에서 처리합니다.

배경 전환은 두 레이어를 사용합니다. 현재 이미지를 보이게 유지한 채 다음 이미지를 불러오고 부드럽게 표시합니다. 네트워크 소스가 실패해도 현재 안정적인 배경을 최대한 유지합니다.

[유연한 배경 소스]

PlainTab은 다음을 지원합니다.

• Bing 일일 배경화면
• Wallhaven
• 로컬 이미지 업로드
• 로컬 배경 폴더
• RSS 이미지 피드
• 사용자 이미지 API
• 비디오 배경화면

간단하게 쓰고 싶다면 Bing을, 개인 배경 컬렉션이 있다면 업로드나 폴더를, 더 세밀하게 꾸미고 싶다면 RSS, API, Wallhaven을 사용할 수 있습니다.

[조용한 홈, 필요한 기능]

PlainTab은 홈을 바로가기 타일로 채우거나 새 탭을 또 다른 피드로 만들지 않습니다.

홈에는 배경화면, 검색, 몇 가지 제어만 남습니다. 바로가기는 명령 팔레트에서 검색, 추가, 편집, 북마크 가져오기, 숨김 공간 관리가 가능합니다.

검색창은 위치, 너비, 둥근 정도, 투명도, 표시 방식, 검색 기록, 검색 엔진 동작을 조정할 수 있습니다.

[깊이 있는 설정]

설정은 별도 패널에 모여 있습니다. 배경 소스, 검색, 단축키, 명령 팔레트, 인터페이스, 백업, 언어 등을 조정할 수 있습니다.

[개인정보와 권한]

PlainTab에는 광고도 추적 분석도 없습니다.

업로드한 배경, 바로가기, 검색 기록, 설정은 주로 브라우저 로컬 저장소에 보관됩니다. 계정이 필요하지 않습니다.

권한은 새 탭, 검색, 페이지 상호작용, 선택적 온라인 배경 소스와 관련됩니다. RSS, API, Wallhaven은 해당 이미지 소스 접근이 필요할 수 있습니다.

[가볍고 열린 프로젝트]

PlainTab은 Vanilla JavaScript, CSS, 브라우저 API로 만들어졌습니다. 프레임워크, 빌드 단계, 큰 런타임 의존성이 없습니다.

오픈소스이며 읽기 쉽습니다. 일상 사용에도, 실제 브라우저 확장 개발을 공부하기에도 좋습니다.

PlainTab은 이런 사람에게 맞습니다.

• 피드 없는 예쁜 새 탭을 원한다
• 일일 배경이나 내 배경 컬렉션을 쓰고 싶다
• 검색, 바로가기, 북마크 가져오기, 백업이 필요하다
• 홈이 수십 개 타일로 가득 차는 것이 싫다
• 가볍고 투명한 확장을 원한다

PlainTab은 추가하지 않습니다.

• 뉴스 피드, 트렌드, 추천 콘텐츠
• 광고나 스폰서 카드
• 계정, 소셜 기능, 클라우드 콘텐츠 스트림
• 홈을 채우는 수십 개의 고정 바로가기
• 자동 재생 홍보 영상이나 피드
