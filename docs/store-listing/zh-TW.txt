PlainTab · 極簡新分頁

一個快速、安靜、以桌布為中心的新分頁。

打開瀏覽器的新分頁時，你應該先看到一張舒服的桌布，而不是新聞流、廣告、熱門榜、推薦內容或滿版小工具。

PlainTab 做的事情很簡單：讓新分頁保持乾淨、好看、反應快。你可以搜尋、輸入網址、開啟捷徑、切換桌布來源，也可以什麼都不做，只看一眼桌布，然後繼續自己的事。

為什麼選 PlainTab？

【打開就有畫面】

PlainTab 很在意新分頁打開時的第一眼體驗。

它會在本機保存輕量的桌布預覽，讓下一次開啟新分頁時盡量馬上有畫面；完整桌布載入、快取和主題色計算會在後續執行階段處理，減少空白閃爍的感覺。

桌布切換使用雙圖層設計：舊畫面會留在底層兜底，新圖準備好後再平滑淡入。即使網路來源失敗，也盡量保留目前可見桌布，而不是把頁面清空。

【桌布自由】

PlainTab 支援多種桌布來源：

• Bing 每日桌布
• Wallhaven 桌布
• 本機圖片上傳
• 本機桌布資料夾
• RSS 圖片源
• 自訂圖片 API
• 影片桌布

如果你只想每天看到一張好看的圖，可以直接使用 Bing 每日桌布。如果你有自己的桌布收藏，可以上傳圖片或選擇本機資料夾。如果你喜歡折騰，也可以接入 RSS、API 或 Wallhaven。

【首頁安靜，功能不少】

PlainTab 不把捷徑鋪滿首頁，也不把新分頁做成資訊流。

首頁預設只保留桌布、搜尋列和少量必要入口。捷徑放在命令面板裡管理：你可以搜尋、新增、編輯、匯入書籤，也可以把一些連結放進隱藏空間，讓首頁繼續保持乾淨。

搜尋列也可以依照習慣調整：位置、寬度、圓角、透明度、顯示方式、搜尋紀錄和搜尋引擎行為。

【設定夠用，但不打擾】

PlainTab 的設定集中在設定面板裡，不會堆在首頁上。

你可以調整桌布來源、搜尋列、快捷鍵、命令面板、介面風格、資料備份、語言等內容。平時看到的仍然是一個安靜的新分頁。

【隱私與權限】

PlainTab 沒有廣告，也不做追蹤分析。

本機上傳的桌布、捷徑、搜尋紀錄和設定資料主要保存在你的瀏覽器本機儲存中。PlainTab 不需要帳號，也不會把新分頁變成雲端內容流。

擴充功能會使用與新分頁、搜尋、頁面互動和可選網路桌布來源相關的權限。RSS、API、Wallhaven 等功能可能需要存取對應圖片來源。

【輕量透明】

PlainTab 使用原生 JavaScript、CSS 和瀏覽器 API 建構，沒有前端框架、沒有建置步驟，也沒有大型執行期依賴。

專案開源，程式碼可以直接閱讀。它適合日常使用，也適合學習瀏覽器擴充功能、前端專案結構和 AI 協作開發。

PlainTab 適合你，如果你希望：

• 新分頁更好看，但不想被資訊流打擾
• 喜歡每日桌布，或有自己的桌布收藏
• 想要搜尋、捷徑、書籤匯入和備份能力
• 不喜歡首頁被幾十個捷徑鋪滿
• 希望擴充功能輕量、透明、可本機執行

PlainTab 不會做什麼：

• 不放新聞流、熱門榜或推薦內容
• 不放廣告、贊助卡片或推廣位
• 不加入帳號系統、社交功能或雲端內容流
• 不把首頁鋪滿幾十個捷徑
• 不播放推廣影片或內容流
