PlainTab · تبويب جديد بسيط

صفحة تبويب جديدة سريعة وهادئة ومرتكزة على الخلفيات.

عند فتح تبويب جديد، يجب أن ترى أولًا خلفية مريحة، وشريط بحث، وروابطك عند الحاجة. ليس موجز أخبار، ولا إعلانات، ولا ترندات، ولا شاشة مليئة بالودجت.

يحافظ PlainTab على صفحة التبويب الجديدة نظيفة وسريعة وشخصية. ابحث، اكتب رابطًا، افتح اختصاراتك، بدّل مصدر الخلفية، أو استمتع بالصورة للحظة ثم تابع عملك.

لماذا PlainTab؟

[خلفية تظهر بسرعة]

يهتم PlainTab باللحظة الأولى بعد فتح التبويب.

يحفظ معاينة خفيفة للخلفية محليًا حتى تظهر الصورة بأسرع ما يمكن عند الفتح التالي. أما التحميل الكامل، والتخزين المؤقت، واستخراج ألوان السمة فتحدث لاحقًا.

تستخدم انتقالات الخلفية طبقتين: تبقى الصورة الحالية ظاهرة بينما تُحمّل التالية وتظهر بسلاسة. إذا فشل مصدر من الإنترنت، يحاول PlainTab إبقاء الخلفية المستقرة الحالية.

[مصادر خلفيات مرنة]

يدعم PlainTab:

• خلفية Bing اليومية
• Wallhaven
• رفع صور محلية
• مجلدات خلفيات محلية
• RSS لصور الخلفيات
• API صور مخصص
• خلفيات فيديو

استخدم Bing إذا أردت تجربة بسيطة، أو صورك المحلية إذا كانت لديك مجموعة خاصة، أو RSS و API و Wallhaven لإعداد أكثر تخصيصًا.

[صفحة هادئة وأدوات مفيدة]

لا يملأ PlainTab الصفحة بالاختصارات ولا يحول التبويب الجديد إلى موجز آخر.

تبقى الصفحة على الأساسيات: خلفية، بحث، وعدد قليل من عناصر التحكم. الاختصارات موجودة في لوحة الأوامر، حيث يمكنك البحث والإضافة والتعديل واستيراد الإشارات وإخفاء الروابط.

يمكن ضبط شريط البحث: الموضع، العرض، الزوايا، الشفافية، طريقة الظهور، سجل البحث، وسلوك محرك البحث.

[إعدادات كافية بدون إزعاج]

تبقى الإعدادات داخل لوحة مخصصة. يمكنك ضبط مصادر الخلفيات، البحث، الاختصارات، لوحة الأوامر، شكل الواجهة، النسخ الاحتياطي، اللغة والمزيد.

[الخصوصية والصلاحيات]

لا يحتوي PlainTab على إعلانات ولا تحليلات تتبع.

الخلفيات المرفوعة، والاختصارات، وسجل البحث، والإعدادات تُحفظ غالبًا في التخزين المحلي للمتصفح. لا تحتاج إلى حساب.

الصلاحيات مرتبطة بالتبويب الجديد، والبحث، والتفاعل مع الصفحة، ومصادر الخلفيات الاختيارية عبر الإنترنت. قد تحتاج RSS و API و Wallhaven إلى الوصول إلى مصادر الصور الخاصة بها.

[خفيف ومفتوح]

بُني PlainTab باستخدام JavaScript عادي و CSS وواجهات المتصفح. لا يوجد framework، ولا خطوة build، ولا اعتماد ثقيل وقت التشغيل.

المشروع مفتوح المصدر وسهل القراءة. مناسب للاستخدام اليومي، ولتعلم كيفية بناء امتداد متصفح حقيقي.

PlainTab مناسب لك إذا أردت:

• تبويبًا جديدًا أجمل بلا موجزات
• خلفيات يومية أو مجموعة خلفيات خاصة بك
• البحث، الاختصارات، استيراد الإشارات، والنسخ الاحتياطي
• صفحة لا تمتلئ بعشرات المربعات
• امتدادًا خفيفًا وواضحًا

PlainTab لن يضيف:

• موجزات أخبار أو ترندات أو توصيات
• إعلانات أو بطاقات ممولة
• حسابات أو ميزات اجتماعية أو تدفقات سحابية
• عشرات الاختصارات المثبتة على الصفحة
• فيديوهات ترويجية أو موجزات تعمل تلقائيًا
