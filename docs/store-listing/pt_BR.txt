PlainTab · Nova guia minimalista

Uma nova guia rápida, calma e centrada em papéis de parede.

Ao abrir uma nova guia, você deveria ver primeiro algo agradável: um papel de parede bonito, uma busca e seus links quando precisar. Não um feed de notícias, anúncios, tendências ou uma tela cheia de widgets.

PlainTab mantém a nova guia limpa, bonita e rápida. Pesquise, digite uma URL, abra atalhos, troque a fonte do papel de parede ou apenas aproveite a imagem por um instante.

Por que usar o PlainTab?

[Papel de parede rápido]

PlainTab cuida do primeiro momento depois de abrir uma guia.

Ele salva localmente uma prévia leve do papel de parede para mostrar uma imagem o quanto antes. O carregamento completo, cache e cores do tema ficam para depois.

As transições usam duas camadas: a imagem atual continua visível enquanto a próxima carrega e aparece suavemente. Se uma fonte de rede falhar, PlainTab tenta manter o papel estável atual.

[Fontes flexíveis]

PlainTab suporta:

• Papel de parede diário do Bing
• Wallhaven
• Imagens enviadas
• Pastas locais
• Feeds RSS de imagens
• APIs de imagens personalizadas
• Papéis de parede em vídeo

Use Bing para algo simples, imagens locais para sua coleção, ou RSS, API e Wallhaven para uma configuração mais personalizada.

[Página calma, ferramentas úteis]

PlainTab não cobre a página com atalhos nem transforma a nova guia em outro feed.

A página mantém o essencial: papel de parede, busca e poucos controles. Os atalhos ficam na paleta de comandos, onde você pode buscar, adicionar, editar, importar favoritos e ocultar links.

A barra de busca permite ajustar posição, largura, raio, transparência, visibilidade, histórico e comportamento do mecanismo de busca.

[Configurações completas]

As configurações ficam em um painel dedicado. Você pode ajustar fontes de papéis, busca, teclas de atalho, paleta de comandos, estilo, backup, idioma e mais.

[Privacidade e permissões]

PlainTab não tem anúncios nem analytics de rastreamento.

Papéis enviados, atalhos, histórico e configurações ficam principalmente no armazenamento local do navegador. Não é necessário criar conta.

As permissões se relacionam à nova guia, busca, interação com a página e fontes opcionais de papéis online. RSS, APIs e Wallhaven podem precisar acessar suas fontes de imagem.

[Leve e aberto]

PlainTab usa JavaScript puro, CSS e APIs do navegador. Sem framework, sem etapa de build e sem dependência pesada.

O projeto é open source e fácil de inspecionar. Serve para uso diário e para estudar uma extensão real de navegador.

PlainTab é para você se quer:

• Uma nova guia mais bonita sem feeds
• Papéis diários ou sua própria coleção
• Busca, atalhos, importação de favoritos e backups
• Uma página sem dezenas de blocos
• Uma extensão leve e transparente

PlainTab não vai adicionar:

• Notícias, tendências ou recomendações
• Anúncios ou cartões patrocinados
• Contas, recursos sociais ou fluxos em nuvem
• Dezenas de atalhos fixos na página
• Vídeos promocionais ou feeds em autoplay
