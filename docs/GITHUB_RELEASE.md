# PlainTab GitHub Release Body

---

**PlainTab v3.2.1**

- Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/plaintab-%C2%B7-minimal-new-ta/jhpfjcefcmooplmaimgdafohdlhacjdo) for automatic updates.
- Or download the `.crx` file below and drag it into `chrome://extensions`.

**Highlights**

- Added Wallhaven as a new wallpaper source.
- Added support for uploading video wallpapers.
- Redesigned the wallpaper setup and apply flow for clearer preview, safer pending changes, and better rollback when preparation fails.
- Refined wallpaper theme colors and the global settings visual hierarchy.
- Improved command palette, shortcut, permission, and API settings interactions.
- Fixed wallpaper apply, settings lazy-loading, and i18n refresh/cache stability issues.
- Added a helper script for packaging release zip files from the latest tag.

**Summary**

v3.2.1 is a wallpaper and settings polish release. PlainTab now supports Wallhaven and video wallpapers, while the wallpaper setup flow is safer and easier to understand: source edits stay isolated until applied, failed preparations roll back cleanly, and status feedback is clearer. The command palette, theme-color behavior, runtime language loading, and settings panel also received stability and usability fixes, making the new-tab experience smoother without changing PlainTab's lightweight vanilla runtime model.

**PlainTab v3.2.1**

- 前往 [Chrome 网上应用店](https://chromewebstore.google.com/detail/plaintab-%C2%B7-minimal-new-ta/jhpfjcefcmooplmaimgdafohdlhacjdo) 安装，可自动更新。
- 或下载下方 `.crx` 文件，拖入 `chrome://extensions` 页面即可。

**更新重点**

- 新增 Wallhaven 壁纸源。
- 新增视频壁纸上传支持。
- 重设计壁纸设置与应用流程，让预览、待应用更改和失败回滚更清晰、更安全。
- 优化壁纸主题色与全局设置视觉层级。
- 改进命令面板、快捷链接、权限设置和 API 设置交互。
- 修复壁纸应用、设置懒加载以及多语言刷新/缓存稳定性问题。
- 新增从最新 tag 打包发布 zip 的辅助脚本。

**总结**

v3.2.1 是一版围绕壁纸与设置体验的打磨更新。PlainTab 现在支持 Wallhaven 和视频壁纸；壁纸设置流程也更安全、更容易理解：来源编辑会在应用前保持隔离，准备失败时可以干净回滚，状态反馈也更明确。命令面板、主题取色、运行时语言加载和设置面板同步获得稳定性与易用性修复，让新标签页体验更顺滑，同时继续保持 PlainTab 原生、轻量、无构建依赖的运行模型。
